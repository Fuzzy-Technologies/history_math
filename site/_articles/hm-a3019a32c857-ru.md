Для произвольного числа номиналов у проблемы Фробениуса о размене монет нет известной общей формулы, хотя многие её случаи полностью решены.

Фердинанд Георг Фробениус (1849–1917) — известный немецкий математик, 175-летие со дня рождения которого отмечалось в 2024 году.

Задача «О размене монет» формулируется так:

«Для заданных положительных целых номиналов с НОД 1 требуется найти наибольшую денежную сумму, которую нельзя набрать монетами этих номиналов».

Например, крупнейшая сумма, которая не может быть получена, используя только монеты номиналом в 3 и 5 единиц, составляет 7 единиц. Этими номиналами нельзя набрать суммы: 1, 2, 4 и 7 (наибольшее), остальные большие суммы — можно.

Можем предложить алгебраическую формулировку задачи для двух взаимно простых натуральных чисел $a,b>1$ (номиналов монет):

Имеются монеты двух номиналов $a$ и $b$ и неограниченное количество монет каждого номинала. Найдите наибольшую сумму $F(a,b)$, которую нельзя выплатить этими двумя номиналами, то есть нельзя представить в виде $xa+yb$, где $x,y$ — целые неотрицательные числа.

Например, $F(3,5)=7$.

Как бы вы её решили? Наш ответ приведён ниже.

## Решение

Для двух взаимно простых чисел $a,b>1$ существует простая формула:

$F(a,b)=ab-a-b$.

Если НОД(a, b) > 1, то существует бесконечное количество сумм, которые нельзя выплатить двумя номиналами. Таким числом является любое число, не делящееся на НОД(a, b).

Если $\gcd(a,b)=1$, то $F(a,b)=ab-a-b$.

Общее количество сумм, которые не представимы имеющимися двумя номиналами, равно:

$\frac{(a-1)(b-1)}{2}$

Для трёх чисел ситуация значительно сложнее. В частном случае, если числа $a,b,c>1$ попарно взаимно просты, то $F(ab,ac,bc)=2abc-ab-ac-bc$.

## Примечания

{% include article-figure.html id="fig-2" %}

Упомянем, что для двух номиналов существует полное решение задачи. Более того, известно также общее количество сумм, которые не представимы имеющимися монетами.

Быстрый алгоритм для F(a, b, c) был найден лишь в 1978 году.

Для больших количеств номиналов общая формула чисел Фробениуса неизвестна. Для любого фиксированного количества номиналов существует алгоритм, который вычисляет число Фробениуса за полиномиальное время.

В итоге, проблема Фробениуса тесно связана с задачами дискретной оптимизации, а также с криптографическими методами защиты информации.
