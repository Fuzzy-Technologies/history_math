Кипрегель (от нем. kippregel, kippen — опрокидываться и regel — линейка) — механический или оптический геодезический прибор, предназначенный для измерения превышений, расстояний, вертикальных углов, графического построения направлений и нанесения их на план рельефа.

{% include article-figure.html id="fig-2" %}

Кипрегель входит в состав мензульного (полевой чертёжный столик) комплекта для топографической съёмки местности. Кипрегель обычно включает в себя:

• стойку;  
• зрительную трубу с дальномерными нитями или визир;  
• вертикальный круг (лимб) с градусными делениями для определения углов наклона;  
• цилиндрический уровень, который используется для нивелирования;  
• масштабную линейку отображения съёмочных точек на мензульном планшете.

{% include article-figure.html id="fig-3" %}

При помощи кипрегеля визируют съёмочные точки. По нитям дальномера определяют расстояние до точки. По вертикальному углу и расстоянию определяют превышение точки. С помощью линейки наносят на планшет линию на точку и расстояние до неё.

Мензульная съёмка, производимая при помощи кипрегеля, применяется, например, на железнодорожных изысканиях для снятия планов мостовых переходов и сложных мест рельефа.

{% include article-figure.html id="fig-4" %}

В нашей стране с 1976 г. серийно выпускался также номограммный кипрегель в двух вариантах.
