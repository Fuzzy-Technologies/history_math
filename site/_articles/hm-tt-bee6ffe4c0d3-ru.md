Инверсор — прибор, с помощью которого строятся фигуры, соответствующие данным в инверсии.

Инверсор используется в технике для превращения кругового движения в прямолинейное, и наоборот.

Такое свойство инверсии используется, например, в инверсоре Липкина–Поселье, — первом плоском шарнирном механизме. Он был придуман в 1860-х годах независимо офицером инженерного корпуса французской армии Шарлем Николя Поселье (1823–1913, Charles Nicolas Peaucellier) и студентом П. Л. Чебышёва Липманом Израилевичем Липкиным (1846–1876). В литературе встречается название «Прямило Липкина». Существуют различные конструкции инверсора.

Геометрические построения для интерпретации механизма Липкина–Поселье указаны на схеме.

Шесть звеньев имеют постоянную длину: OA, OC, AB, BC, CD, DA. Длина звена OA равна длине OC. Длины звеньев AB, BC, CD, DA равны между собой, которые образуют ромб. Точка O остаётся неподвижной. Если точка B производит вынужденное движение по окружности (на рисунке показанной красным), проходящей через точку О, то точка D обязательно будет двигаться по прямой линии (показана голубым). С другой стороны, если точка B будет вынужденно двигаться по прямой (не проходящей через О), то точка D будет двигаться по окружности, проходящей через О.

Этот механизм реализует инверсию относительно окружности с центром в закреплённом шарнире O и радиусом, зависящим от длины звеньев механизма.

Инверсор можно использовать как практическое пособие для образовательных целей. Например, инверсор «Фибоначчи» (на фото в начале статьи) может быть использован для демонстрации преобразования инверсии на уроках геометрии.
