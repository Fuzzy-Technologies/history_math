Пантограф — инструмент для вычерчивания гомотетичных фигур (рисунков, планов, карт). С помощью пантографа производят подобное копирование. Такой механический прибор изобрёл в 1603 г. Христофор Шейнер и назвал его пантографом, основываясь на греческих словах πᾶν или παντός (всё, всякий) и γράφω (пишу, рисую, описываю), то есть буквально «тот, что всё пишет».

{% include article-figure.html id="fig-2" %}

Пантограф может иметь различные конструкции. Его теория описывается во многих учебниках геометрии, например, у А. П. Кисёлева даётся рисунок и объясняется теория инструмента, основанная на гомотетии.

{% include article-figure.html id="fig-3" %}

{% include article-figure.html id="fig-4" %}

Обычная конструкция пантографа содержит параллелограмм, сторонами которого служат металлические стержни, вращающиеся на шарнирах вокруг вершин. Одна из вершин укрепляется неподвижно, она исполняет роль центра гомотетии. На продолжении одной из сторон устанавливается штифт, описывающий заданную фигуру. Тогда карандаш, установленный на отрезке между этими точками на расстоянии, определяемом коэффициентом гомотетии, описывает подобную фигуру. Установление этого факта — элементарная геометрическая задача.

{% include article-figure.html id="fig-5" %}

Самодельный пантограф, который можно изготовить из пяти планок равной длины из детского набора «Конструктор», описан Г. М. Михайловым. На этих планках просверлены отверстия, расположенные на равных расстояниях друг от друга. Четыре планки образуют ромб, а положение пятой регулируемой планки определяется коэффициентом подобия.

{% include article-figure.html id="fig-6" %}

{% include article-figure.html id="fig-7" %}

Пантографы используются и в быту. Например, их можно обнаружить в механизме трансформации диванов-кроватей, в гибких стойках для удобного расположения микрофона перед диктором или прожектора для съёмки, в удлинителе для зеркала, в деталях крепления клавиш компьютерной клавиатуры, и даже в устройстве токоприёмников электропоездов и трамваев.
