Буссоль (франц. boussole, компас) — геодезический инструмент для измерения горизонтальных углов между магнитным меридианом и направлением на какой-либо предмет (магнитных азимутов, румбов направлений).

Буссоли являются усовершенствованными компасами с приспособлениями для визирования и более мелкими делениями градусного круга, которые устанавливаются на штативах.

{% include article-figure.html id="fig-2" %}

Из числа технических буссолей, которые удобно использовать для работы в школе, следует отметить буссоль Стефана. Прибор был сконструирован в середине XIX века военным инженером, начальником Николаевской академии Генерального штаба Густавом Стефаном. Он представляет собой наружный круг, называемый лимбом, с градусными делениями. Для визирования направления около вертикальной оси вращается линейка, называемая алидадой. Край алидады скошен к лимбу, и на нём нанесены деления верньера, дающие возможность получить доли градуса.

Визирование производится через диоптры и на алидаде. Они изготовляются в виде вертикальных пластинок. Одна из пластинок называется глазной, а другая — предметной.

На наружном лимбе буссоли помещается плоская цилиндрическая коробка, которая и представляет, собственно, буссоль с магнитной стрелкой. На внутреннем лимбе нанесены деления через один градус.

{% include article-figure.html id="fig-3" %}

Буссоль используется при проведении топографических и геодезических работ, для ориентировки планшета. Области её применения: геология, археология и лесное хозяйство.

{% include article-figure.html id="fig-4" %}

В военном деле она используется для выполнения топографической привязки элементов боевого порядка войск. Существует перископическая артиллерийская буссоль, которая применяется для управления огнём артиллерии, целеуказания, изучения местности и наблюдения за стрельбой.

Использующийся в морском деле компас — пеленгатор — тоже разновидность буссоли.
