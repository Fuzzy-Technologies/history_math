Mathematicians are joking and proving the theorem “All horses are the same colour”. 🐎🐎🐎

## Proof by induction

For $n=1$:<br>
The claim obviously holds for a set containing one horse.

For $n=k$:<br>
Assume that in every set of $k$ horses, all the horses are the same colour.

For $n=k+1$:<br>
Take a set containing $k+1$ horses. Remove one horse, leaving $k$. By the induction hypothesis, they are all the same colour. Now return the removed horse and take away a different one. By the induction hypothesis, these $k$ remaining horses are also the same colour. Continuing in this way, all $k+1$ horses are therefore the same colour.

By the principle of mathematical induction, all horses are the same colour.
