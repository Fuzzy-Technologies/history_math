Анаглиф (от греч. αναγλνφον — рельеф, барельеф) — стереоскопический чертёж, отличающийся от обычного тем, что состоит из двух частей (чертежей), помещённых друг над другом и выполненных в двух разных красках (бледно-красной и бледно-зеленой). Анаглиф рассматривается через специальные очки — светофильтры (стереоочки), имеющие разные цвета (чаще всего красный для левого глаза и сине-зеленый для правого).

{% include article-figure.html id="fig-2" %}

По известным законам физики и физиологии каждый глаз воспринимает только одно из двух изображений, так как каждый из светофильтров очков взаимно поглощает соседнее изображение. Таким образом, при совмещённом двойном (бинокулярном) рассмотрении анаглифа, создаётся единое стереоскопическое (объёмное) изображение.

Анаглиф используется для иллюстраций по стереометрии, кристаллографии и объёмной мультипликации для получения стереометрических кинофильмов, создания объёмных моделей местности.

{% include article-figure.html id="fig-3" %}

В 1963 году был выпущен альбом В. Г. Владимирского «Стереометрические чертежи по геометрии» в двух частях в качестве учебного пособия для учащихся старших классов. В первой части иллюстрируется учебник А. П. Киселёва по стереометрии издания 1951 г. и более поздних лет. Во второй части изображены фигуры к задачам Н. А. Рыбкина, входящих в «Сборник задач по геометрии» издания 1955 г. и более поздних лет.

Сейчас возможно имитировать использование цветовых фильтров с помощью специальных компьютерных программ. Средства для создания анаглифов есть, например, в популярном профессиональном программном обеспечении Adobe Photoshop. Этим способом мы сами сделали анаглиф (изображение в начале статьи).
